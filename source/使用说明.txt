CodexHub 1.7.0 稳定版

安装与使用：
1. 双击 CodexHub-1.7.0-Setup.exe，选择本地磁盘的安装路径，无需解压。
2. 在本地壁纸导入 MP4、WebM、GIF、PNG、JPG 或 WebP，也可选择内置《花桃全屏》静态背景。
3. 选中卡片在右侧预览，再点“应用这张壁纸”；导入和预览不会改变当前背景。
4. Wallpaper Engine 自动扫描 Steam 库，也可手动定位 Steam 库或 431960 目录。搜索、筛选后连续向下滚动。
5. scene.pkg、网页、应用项目只使用已有图片或 GIF 预览，不直接运行原场景。
6. 使用记录只在成功应用后保存。移除记录不删除用户原文件。

服务与设置：
提供装载服务、卸载皮肤、卸载服务、重新检测和更新软件。
左下角显示连接、服务及实际壁纸状态，点击可重新检测。
“更新软件”从本项目 GitHub 发行页检查、下载程序更新，校验后重开管理器。
程序更新保留安装路径、壁纸与宠物素材、使用记录、大小与活动范围等设置，只替换软件和必要的后台组件。
首次升级到带此按钮的版本需要运行本版安装程序；此后在软件内更新即可。
安装包可升级旧 EXE 安装，旧 MSI 迁移需要时请求原账号的 Windows 授权。
桌面只创建一个 CodexHub 管理器快捷方式，后台组件与程序统一位于所选安装目录。

后台与连接：
最小化或关闭管理器隐藏到右下角托盘。双击托盘或右键打开恢复；选择退出管理器才结束桌宠。
背景服务独立运行，随 Windows 登录和 Codex 启动恢复，登录时不弹出管理器。
首次连接遇到普通启动实例时，请保存输入并手动完全退出 Codex 一次，再应用壁纸。
程序更新不会关闭 Codex 聊天窗口。
图片按比例裁切铺满 Codex，聊天框不透明度越低越透明。应用壁纸时启用 Codex 深色外观。
预览失败会降低预览清晰度，最后尝试静态缩略图；不会因此降低已应用原片画质。

内置与视频兼容：
新装仅内置《花桃全屏》静态背景；其他壁纸可从本地或 Wallpaper Engine 导入。
升级保留已有壁纸与有效原片。
鲸鱼女仆的 106 段宠物动画仍随包提供，不受壁纸视频按需下载影响。
支持 4K 原片；当前 Codex 无法解码时，兼容副本按源尺寸（长边最高 4096）、2560、1920 逐级尝试。
兼容副本为静音 VP9 WebM，最高 30 FPS，保留完整时长，不改用户原文件。
视频源文件最大 2 GiB，最终播放副本最大 512 MiB；最长 10 分钟，输入最高 120 FPS。
单边最高 16384 像素、总像素最高 50 MP；图片最大 512 MiB，图片动画最多 300 帧。
主题名称最多 4096 个 Unicode 码点，不允许换行或控制字符。
本安装包已内置并校验 FFmpeg 运行时，透明桌宠和视频转换无需另装解码器。
所有转换在本机完成，详情和运行时许可见 THIRD_PARTY\FFmpeg-Runtime。
下载、导入和转换在后台进行，不暂停桌宠和卡片动画。

桌面宠物：
左侧选择“桌面宠物”，默认列表为鲸鱼娘、鲸鱼女仆、白龙娘，可导入标准 ZIP 或 pet.json。
白龙娘优先读取本机原素材，也可从作者固定发布准备 25 段完整透明动画；作者图像不重新打包发布。
鲸鱼娘提供 32 项表情与轻动画；鲸鱼女仆提供 106 段完整透明动画。
拖动跟随鼠标，松手结束悬空动作并保留惯性。普通点击不先播放飞行动画。
边界回弹并播放自身碰撞反馈；鲸鱼娘受惊后防御两秒，鲸鱼女仆用尾巴拍打地面。
活动范围在右键菜单和管理器统一切换：仅在 Codex 内，或整个桌面。
自主行走和惯性固定在当前显示器内，只有手动跨屏拖动才换屏。
Codex 内模式随已验证窗口最小化或恢复；桌面模式保持置顶。
点击和空闲动作优先轮换尚未播放的可用动作，任务开始工作、结束完成，五分钟无任务只进入一次休息。
碎碎念及气泡已取消。右键静音，左右键均有轻微按压反馈。
宠物和胶囊大小分别设置，范围 70%～150%，默认 100%；鲸鱼女仆新 100% 对应此前实际大小的 80%。
点击胶囊展开当前任务与操作，点击圆环展开额度、重置时间和 Token 曲线，刷新时圆箭头转动。
卡片跟随宠物继续动画和走动，等待主动收起；靠近顶部时小胶囊移到宠物下方。
右键菜单与卡片互斥，点击菜单外关闭，不显示隐藏管理器的任务栏图标。
额度只读本机已登录 Codex 的 app-server，未知或过期明确标记，不生成任务。
Token 统计含缓存输入，不等于账单；任务索引只读标题和事件类型，不上传对话。

卸载与资料：
卸载皮肤只解除效果，服务保留。卸载服务移除后台组件，管理器文件保留。
完整卸载使用安装目录中的“卸载 CodexHub.exe”或 Windows 设置卸载。
卸载先停止本项目组件、解除自启动和挂接，再移除核验过的程序及缓存，不关闭 Codex 聊天、不删除用户原壁纸。
个人设置和播放缓存位于 %LOCALAPPDATA%\CodexDreamSkin，属于当前用户数据。
诊断文件是该目录下的 last-video-diagnostic.json，服务日志在安装目录的 startup 中。
当前发行尚未正式代码签名，Windows 提示说明见 docs\windows-trust.md。

跟随 Codex 自动启停：在桌面宠物的陪伴方式中开启。Codex 最小化、隐藏到托盘或退出后，管理器和宠物正常退出；Codex 打开或恢复时，在托盘自动启动，主窗口不弹出。切换其他软件不会退出。后台保留轻量检测组件以便恢复。手动退出管理器后，等下一轮 Codex 隐藏再恢复才重新启动。导入、更新或模态选择器打开期间等待工作完成。开关默认关闭，不改变原使用习惯。
胶囊与圆环：宠物列表下方点击统一配色可一次更改左侧 Hub 按钮、中间胶囊和右侧圆环，也可分别选色。胶囊与圆环不透明度用 0～100% 滑条调节，实时预览、松手保存；数值越低底色越透明，文字不跟随变淡。点击恢复默认可恢复三处蓝色与 94% 不透明度。右侧只保留刷新真实额度和互动与动画设置。
