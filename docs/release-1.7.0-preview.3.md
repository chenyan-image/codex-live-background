## 本次修复

- 卡片展开不再暂停宠物。两种卡片随动画、行走、拖动和滑行保持相对位置，主动收起后恢复小胶囊；靠近顶部时胶囊转到下方。
- 普通点击没有飞行前置动作，超过拖动阈值才进入悬空姿态。拖拽原片预热并加速起步，持有时保持；松手立即结束飞行，惯性位移继续。碰撞、拖拽及退出不交叉叠加两种姿态。
- 四只宠物共用菜单、范围、惯性和动作调度。点击／空闲按共享播放记录轮换，五分钟无任务只进入一次休息；碎碎念和气泡已取消。鲸鱼女仆没钱动画仅在真实剩余额度低于 10% 时加入自动／点击池。
- 鲸鱼娘碰撞为受惊 850 ms → 防御 2000 ms，鲸鱼女仆播放完整尾巴拍地原片。碰撞计入当前可见姿态和桌子，留约 8 逻辑像素余量；固定当前显示器，主动跨屏拖动才换屏。
- 三种视频行走按实际解码进度及原片起步／收尾段同步位移。素材后台准备、静态图库和批量菜单布局减少切换停顿；已验证窗口快速检测 Codex 最小化／恢复，隐藏期间暂停视频时钟。
- 版本检查读取当前包清单，消除写死 1.6.2 的上限。自选路径旧 EXE 安装从 Windows 卸载登记发现；先检查服务路径、用户、参数及发布哈希，再停止旧组件。支持自选路径备份和回滚，拒绝外部同名任务及未知组件。
- 六张旧内置背景换成四项：花桃、神里绫华、德累斯顿预览 GIF、雨樱完整 4K 原片。雨樱保留 3840×2160、30 FPS、86.7 秒、101871488 字节，不缩减为预览视频。个人导入和历史记录保留。
