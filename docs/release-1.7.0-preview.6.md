# CodexHub 1.7.0-preview.6

内部构建 **1.7.0.9**。1.7.0.8 是此前本地检查用候选；递增构建号使候选也能收到本次修复。功能分支 feature/pet-companion，稳定版 latest 保持 v1.5.4.5。

## 更新内容

- 任务卡片跟随胶囊颜色，额度卡片跟随圆环颜色，图表、文字和刷新图标一起适配。左右圆形底色与中间胶囊共用不透明度滑条，Logo 和文字保持清晰，旧设置数值沿用。
- 公开更新频道优先检查，避免 GitHub 匿名 API 限流导致的 403。成功结果短时缓存，并发检查合并；接口受限时显示重试时间，下载仍验证版本、大小和 SHA-256。
- 启动时仅检查 GitHub；有可用版本时“更新软件”按钮显示小红点，点击后才下载和安装。无更新时显示当前预览名称和内部构建号，避免把预览误称正式最新版。
- “跟随 Codex”检测移入已有背景守护，退役旧 updater Run 登记。CodexHubUpdater.exe 只在实际更新时短暂运行。程序更新会合作停止并恢复自己的守护，Codex 聊天窗口不关闭。
- 左下角连接区增加空间；点击立即显示连接或排队进度，实际核对服务与端口。连接可用但皮肤丢失时恢复保存的壁纸，尊重暂停。守护中的渲染健康检查处理启动加载后的样式丢失。
- 从校验过的 preview.3、preview.4、preview.5 安装包提取封闭历史清单与 EXE 指纹，修复合法旧文件被误判“未经核验”以及安装标记缺失后的重试。安装源在停止服务前整包验证；可接管文件与任务归属均核验通过的旧服务路径，未知来源仍拒绝。
- 预览模式禁止修改真实服务、连接和程序安装，避免测试窗口与已安装程序争用控制权。
- 新安装仅附《花桃全屏》壁纸；鲸鱼娘与鲸鱼女仆内置，白龙娘保留作者下载入口。女仆的 106 段完整动画随包提供，无需再次下载动画；通用播放／视频转换组件首次需要时下载并缓存。
- 两个角色预览按身体轮廓正常居中显示。白龙娘从作者固定 GitHub 版本获取约 0.4 MB 预览，缓存后复用，不必先下载完整动作。
- Codex 内模式只识别已验证主窗口，排除任务栏右键菜单、跳转列表和工具窗口。
- 程序更新保留壁纸、宠物、通用运行时、个人设置与记录；只更新程序和必要的守护代码。已安装同版本或更高版本时，从检查／下载目录打开会复用已验证安装入口，减少不同路径造成的混用。
