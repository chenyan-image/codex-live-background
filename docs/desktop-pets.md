## 动作和交互

收到任务 → 工作／整理／等待 → 完成或错误。空闲时按权重选择日常动作，五分钟无任务后睡觉／休息。动作正常播完后再切换，候选不连续重复；拖拽、碰撞即时响应。没有某种专用素材的宠物使用自身最接近的动作，不在菜单中冒充未提供的动画。

打开随机行走后，通常停留 12～24 秒，再随机选方向低速走一小段；日常动作之间穿插至少约 8 秒待机。执行状态不会压住走动计时；右键“恢复自主走动”会清除手动占用并重新开始。拖动松手带惯性并减速，暂停拖动后松手不甩动，碰到允许范围的四边或角落回弹并显示明亮星星。

所有宠物共用右键活动范围：Codex 内或整个桌面，支持跨屏拖动。窗口内模式随 Codex 移动，最小化时隐藏；桌面模式保持置顶。菜单外点击关闭，打开菜单时暂停移动及置顶重申，不激活隐藏管理器、不新增任务栏按钮。

左右键都有轻微缩小和平滑恢复；右键静音。左键点击 WAV 已嵌入 EXE，独立于原电脑目录。宠物大小与上方胶囊分别调节，默认 100%，范围 70%～150%；宠物新 100% 等于旧 140%。

## 胶囊和圆环

胶囊显示当前任务和最近操作；圆环显示短周期／本周剩余、Token 曲线、重置时间。弹窗在独立工具窗口中约 320 ms 从被点击的胶囊／圆环向上展开，宠物身体不移动、不缩放。刷新矢量圆箭头只在实际读取期间转动。

额度只读本机已登录 Codex 的 app-server；未知／过期保持原意。六档事件按实际已用比例 0–19%、20–39%、40–59%、60–79%、80–99%、100% 选择动作；右键动作预览不修改额度。Token 来自本机增量计数，含缓存输入，不等同账单。

任务标题从本机 SQLite 索引只读查询，操作只取事件类型、工具名和时间。不查询聊天正文／命令参数，不写回数据库、不上传内容。

## 离线碎碎念

每只宠物分别保存自动开关、间隔与动画权重，默认 300 秒。右键“碎碎念”随时触发，不受自动开关限制；气泡约十秒消失，采用蓝色圆角、小尾巴与爱心，14 像素字体自动分行。离线互动使用软件内原创中文文案，不调用 Codex 或其他模型、不消耗额度、不保存聊天。

## 加载与来源

白龙优先使用本机 BailongEnhanced 原素材，否则校验作者固定发布后本地转换。小蕾米从作者固定版本下载原图集、pet.json、ASSET-USAGE.md、NOTICE.md，校验并保留原说明。两者原图不重新托管。现有旧白龙 12 FPS 副本不会自动增加帧，需要重新准备。

导入支持网站 ZIP 或本地 pet.json 的 PNG／WebP 标准图集。ZIP 路径穿越、超限或错误布局会被拒绝，不执行包内脚本。鲸鱼女仆使用发行版内置透明视频格式；下载作者示例 GIF 的低分辨率预览不作为生产播放器。
