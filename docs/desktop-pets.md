# 桌面宠物

CodexHub 的左侧「桌面宠物」页面与动态背景共用同一个管理器。点击形象立即切换，偏好自动保存。首次打开默认使用鲸鱼娘，并在 Codex 窗口内显示；需要先打开本机官方 Codex。

| 操作 | 结果 |
| --- | --- |
| 拖动角色 | 移动宠物；Codex 内模式限制在其客户区，桌面模式可跨屏拖动 |
| 双击角色 | 播放打招呼动作和轻提示音；设置可静音 |
| 允许随机行走 | 随机行走与短暂停留，碰壁反向并出现回弹、受挫动作和星星 |
| 右键 | 打开设置、刷新额度、预览九种基础动作、隐藏宠物；白龙娘另有完整 25 段动画 |
| 点击右侧圆环或胶囊 | 展开紧凑额度卡片，再点卡片收起 |
| 点击左侧 Hub Logo 圆形按钮 | 打开管理器的桌面宠物页 |
| 点击展开卡片右上刷新图标 | 重新读取真实额度 |
| 右侧 Token / 重置 | 切换本机用量曲线与两项具体重置日期 |
| 今日 / 7天 / 30天 | 切换曲线统计周期；今日横轴为 00—24 时，其他周期按天显示 |

在「仅在 Codex 窗口内」模式下，宠物跟随 Codex 窗口移动。Codex 最小化或关闭时隐藏，恢复后出现；点击其它应用时仍保持置顶。桌面模式按显示器工作区限制，避开任务栏，拖动可换屏；管理器或右键「活动范围」都能切换。

「宠物大小」只改变角色，「胶囊大小」只改变上方胶囊，二者默认 100%。窄小窗口优先缩小宠物以保留胶囊可读性。普通图集拖动时保持正常体型；白龙使用作者原拖拽动画。根菜单、子菜单和托盘菜单统一圆角深色，点击外部会关闭；打开菜单时暂时停止随机移动与置顶重申，不反复激活窗口。

默认悬浮层是蓝色小胶囊和一个圆环，执行／思考时三点旋转，结束或等待确认时停下。展开卡片约 **268 × 220 逻辑像素**，不使用大字号面板；实际像素随系统 DPI 和宠物大小设置变化。拉丁字母和数字使用 Chakra Petch，中文使用微软雅黑，刷新按钮使用 Phosphor 原始图标。双击提示音由程序合成，不是角色配音。所有角色保留原图集和动画帧。

额度通过本机 Codex CLI 的 `app-server` / `account/rateLimits/read` 读取，使用该 CLI 已有的登录状态。不会生成聊天任务，也不读取、导出或打包登录凭据。定期两分钟刷新，可手动刷新；超过五分钟的读数显示过期。没有返回的额度和重置时间显示未知。各周期名称根据服务返回的分钟数显示；并非所有账号都有相同窗口。

重置显示实时倒计时，如「3时27分后重置」「6天22时后重置」；右侧重置页签显示本机时区的具体日期和时间。已到时间但服务器尚未返回新值时显示「等待额度更新」，不会擅自把额度改为 100%。

Token 曲线来自 `%CODEX_HOME%`（默认 `%USERPROFILE%\.codex`）的 sessions 和 archived_sessions，本机最近 30 天按小时／天汇总。新格式按每次响应统计并按响应 ID 去重；旧格式取累计计数的正向增量，并排除复制记录的重复值。输入包含缓存输入，输出包含模型报告的输出；不重复加上 reasoning 子项，不等同于账单。首次扫描在后台分批进行，期间标记统计中；随后增量读取。仅保留时间、数字与去重键，不保存、显示或上传对话正文。

执行状态只读取本机任务事件类型和时间，不显示聊天正文；未在该电脑记录的云端任务不会出现在胶囊里。

导入支持网站下载的 ZIP 或本地 `pet.json`：PNG / WebP 透明图集，v1 为 1536×1872，v2 为 1536×2288。九种基础动作都需包含有效帧。ZIP 只读取清单、对应图集和有限的来源／许可文件，不执行包里的程序或脚本；超限大小、路径穿越和错误图集会被拒绝。WebP 需要首次准备现有 FFmpeg 转换运行时；九个内置 PNG 图集离线可用。

白龙娘与小蕾米保留作者素材加载入口，不将其原图像重新打包发布。白龙优先识别本机 BailongEnhanced 的原素材目录，否则从固定作者发布下载约 589 MiB 的原包，并校验大小与 SHA-256 后转换 25 段完整动画；也可通过导入选择原目录中的 `素材清单.json`。小蕾米从固定作者版本下载原图集、pet.json、ASSET-USAGE.md 和 NOTICE.md，逐个核验并在本机转换，原声明随本地副本保存。

宠物设置在 `%LOCALAPPDATA%\CodexDreamSkin\pet-settings.json`，导入副本在同目录的 `pets` 下。原下载文件不修改。管理器最小化或关闭时进入托盘，宠物继续运行；「退出管理器」一起退出宠物和自有子进程，壁纸服务独立运行。完整卸载清理宠物设置、导入副本和安装资源，保留外部原文件和 Codex 登录资料。

功能预览可直接从构建目录运行：

```powershell
.\CodexLiveBackground.exe --pet-preview D:\CodexHubPreview\state
```

此入口使用单独的宠物资料目录，不装载或重配当前背景服务，适合先试用界面和桌宠。多个预览窗口应手动退出后再打开，避免同时看到两只宠物。
