## 动作和交互

收到任务 → 工作／整理／等待 → 完成或错误。点击和空闲动作共用播放记录，优先轮换尚未播放的可用动作；分类优先级只影响同轮顺序，设为 0 可禁用该分类的自动播放。五分钟无任务后只进入一次睡觉／休息，播完保持最后姿态，点击、恢复自主走动或新任务可唤醒。正常切换等待完整动作播完；拖拽、碰撞即时响应。没有某种专用素材的宠物使用自身最接近的动作，不在菜单中冒充未提供的动画。

打开随机行走后，通常停留 12～24 秒，再随机选方向走一段明显距离，随宠物实际大小和 DPI 缩放；日常动作之间穿插至少约 8 秒待机。执行状态不会压住走动计时；右键会清楚显示“恢复自主走动”或“暂停自主走动”，不显示勾选标记；恢复后马上准备一段行走。拖动松手带惯性并减速，暂停拖动后松手不甩动，碰到允许范围的四边或角落回弹并播放自身反馈。鲸鱼娘按“受惊 → 抱头防御 2 秒 → 原工作／待机”播放，鲸鱼女仆播放“用鲸鱼尾巴拍打地面”。碰撞按可见身体计算，忽略透明画布和上方胶囊，按当前姿态（包括工作桌子）留约 8 个逻辑像素的贴边余量。

所有宠物共用右键活动范围：Codex 内或整个桌面。桌面模式固定当前显示器，自主行走或惯性不会跳到邻屏；只有手动跨屏拖动才更换显示器。坐标统一为物理像素，兼容不同缩放比例。窗口内模式随 Codex 移动，每次绘制直接检测已验证窗口的最小化状态，快速隐藏／恢复，视频暂停期间不追帧；桌面模式保持置顶。菜单外点击关闭，打开菜单时暂停移动及置顶重申，不激活隐藏管理器、不新增任务栏按钮。

左右键都有轻微缩小和平滑恢复；右键静音。左键点击 WAV 已嵌入 EXE，独立于原电脑目录。宠物大小与上方胶囊分别调节，默认 100%，范围 70%～150%。鲸鱼娘与白龙娘沿用此前放大的基准；鲸鱼女仆在预览 4 将此前实际大小的 80% 校准为新 100%，不重置保存的滑条值。

## 胶囊和圆环

胶囊固定跟随可见身体上方，独立于透明画布。胶囊显示当前任务和最近操作；圆环显示短周期／本周剩余、Token 曲线、重置时间。弹窗在独立工具窗口中约 320 ms 从被点击的胶囊／圆环展开，展开动作不会额外移动或缩放宠物。刷新矢量圆箭头只在实际读取期间转动。打开右键菜单会收起卡片，打开卡片也会关闭菜单，所有形象共用相同的工具窗口和交互规则。接近顶部时胶囊自动放在下方并带 12 像素切换回差。卡片展开期间，宠物继续播放动作、行走和惯性滑行，卡片跟随身体保持相对位置；点击别处不收起，点击收起箭头恢复小胶囊。上方空间足够时放在头部上方，空间不足时保证卡片完整可见。

额度只读本机已登录 Codex 的 app-server；未知／过期保持原意。一般形象按六档事件选择自身回应；鲸鱼女仆的没钱系列只有真实剩余额度小于 10% 才自动随机触发，未知或达到 10% 时不进入普通点击／随机池；右键动作预览不修改额度。Token 来自本机增量计数，含缓存输入，不等同账单。

任务标题从本机 SQLite 索引只读查询，操作只取事件类型、工具名和时间。不查询聊天正文／命令参数，不写回数据库、不上传内容。

## 行走与拖拽

鲸鱼女仆自主行走跳过原片静止起步，三种动作从有效移动帧与实际位移一起开始；只按已显示的帧移动，解码等待时不先滑走。方向与动作朝向对应，右键手动预览仍播放完整原片。

普通按下只做轻微按压反馈；鼠标实际移动超过阈值后才使用预热的拖拽原片，开头加速 3.5 倍进入悬空动作，持续拖动时保持该姿态。位置先跟随鼠标，画面最多约 90 FPS 重绘，首次拖动立即绘制，避免重绘阻塞输入。松手立即结束悬空动作并回到待机，惯性位移继续减速；新画面就绪前使用已加载的待机图，避免残留飞行帧。碰撞、拖拽及其退出直接切换画面，避免旧姿态与新姿态叠加。显示进度按实际帧计时，绘制卡顿时限制跳帧，位移不追赶尚未显示的时间。

碎碎念的自动触发、设置、右键入口和气泡已移除，旧设置也不会重新开启。保留独立的本地文案对话窗口，不调用模型、不消耗额度。图库使用静态首图，完整素材在后台准备；原宠物保留到新形象准备完成，窗口只在 UI 线程创建。

## 加载与来源


导入支持网站 ZIP 或本地 pet.json 的 PNG／WebP 标准图集。ZIP 路径穿越、超限或错误布局会被拒绝，不执行包内脚本。鲸鱼女仆使用发行版内置透明视频格式；下载作者示例 GIF 的低分辨率预览不作为生产播放器。

预览 4：鲸鱼女仆的 100% 按此前 80% 的实际尺寸校准，滑条范围仍为 70%～150%，胶囊比例独立。自主移动跳过原片的静止起步段，从有效跑动段与位移一起开始；手动预览仍播放完整素材。下载和本地导入不暂停宠物，导入进度合并显示。

当前默认列表仅保留鲸鱼娘、鲸鱼女仆和白龙娘，小蕾米入口已移除。用户个人导入与缓存不因程序更新而清空。

内存处理：鲸鱼娘按需读取动作图，解码缓存最多 8 张并限制为 4 MiB（单个更大的自定义图集仍可单独加载）。静态缩略图不保留整段 GIF；预览隐藏后释放图片，重新显示时恢复。Token 扫描复用缓冲，只解析统计记录，不为无关日志建立大量字符串。

## 启停与外观

“跟随 Codex 自动启停”默认关闭。开启后，Codex 最小化、隐藏到托盘或退出时，管理器和宠物正常退出；恢复或打开 Codex 后自动从托盘启动。只是切换其他软件不会退出，多窗口只要有一个可见就继续运行。后台保留已有更新组件的轻量检测模式，用于发现下一次恢复，没有常驻宠物解码器或图片缓存。手动退出管理器后，等下一轮 Codex 隐藏再恢复才重启。导入、更新和选择器打开期间会等待工作完成。

宠物列表下方的“统一配色”可一次更改左侧 Hub 按钮、中间胶囊和右侧圆环，也可分别选择三处颜色。胶囊不透明度用 0%～100% 滑条调节，实时预览、松手保存。数值越低底色越透明，文字不跟随变淡。旧设置中左侧按钮继承原圆环颜色。恢复默认只重置这四个外观值，不改变宠物、大小或活动范围。原来的两个手动动作按钮已移除，刷新额度和互动设置移到上方，宠物右键动作继续保留。
