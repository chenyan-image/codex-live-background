# CodexHub 抖音功能预览 4

内部版本 `1.8.0.4`，功能分支 `codex/douyin-spark`，基于稳定版 v1.7.0.6。

- 修复任务开始时管理器挡住抖音、触发“抖音已切到后台或窗口已变化”的问题。任务期间管理器暂时收进托盘，托盘菜单可停止任务，进度更新不再重建名单。
- 加入 Windows 原生局部 OCR，定位消息栏和表情区域；通过原生控件点查核对联系人完整名称及搜索内容。无需 Python、Codex 或在线识别服务，缺少可用 OCR 时回退到控件定位。
- 消息搜索统一使用已验证焦点的 Unicode 键盘输入，避免直接赋值只回显、不触发实际搜索。输入后继续回读核对，禁止按模糊名称选择联系人。
- 宠物引导移动缩短为约 0.18～0.55 秒，减少重复读取；页面等待阶段采用 8 秒轮询预算，任务结束显示本轮耗时。
- 保留检查名单不发送、同名待确认、找不到人跳过、取消和当天操作记录。实际点击前再次核对联系人；无法取得明确发送回执时显示“已点击·待确认”，当天不自动重发。
- 修复视觉和控件后端交替造成的搜索结果反复不稳定；使用连续的完全同名数量核对目标，额外文字变化不再阻塞唯一同名结果。搜索结果中优先点击同一行的“发消息”按钮，并保存不含联系人名称和正文的最近一轮诊断摘要。
- 聊天标题增加原生定向读取，核对被省略显示的完整名称；搜索框允许短暂焦点延迟，仍在限定次数内验证后才输入。修复浮动通知及嵌套发送箭头图像影响表情定位的问题。

验证记录：截图视觉检查 15 项、流程检查 67 项、独立运行 11 项、原宠物渲染 24 项通过，原画面校验值未变。实机消息栏只读视觉定位为 736 毫秒、764 毫秒；完整单人“不发送”检查模式通过，用时 25.9 秒，已找到联系人和续火花表情，未点击发送。真实发送和整份名单一分钟完成目标尚未验证。

本版仅更新独立体验分支，未合并 `main`，未修改稳定版下载和更新渠道。
