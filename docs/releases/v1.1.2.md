# v1.1.2 — 修复跨电脑视频播放，自动生成兼容背景

本版修复其他电脑使用视频背景时出现 `playback-rejected` 的问题。现在会区分播放权限、窗口隐藏、播放中断和真正的编码不支持；当当前 Codex 确实无法解码 MP4 时，自动生成并验证 VP9 WebM 兼容副本。

## 主要变化

- 视频探针和背景首次播放明确设置静音，并正确处理用户发起的媒体播放请求。
- 编码不兼容时生成无音轨 VP9 WebM，长边最高 1920 像素、30 FPS，保留完整时长和原文件。
- 自动转换后仍检查 WebM 容器、视频轨、时间戳和尺寸，并在当前 Codex 验证真实解码帧。
- 兼容副本缓存复用；下载、转换或验证失败时保留当前壁纸。
- 首次需要转换时下载约 74 MiB 的固定 LGPL FFmpeg 运行时，校验 SHA-256；支持将同一原始 ZIP 放入缓存目录离线使用。具体地址和校验值见包内 `THIRD_PARTY/FFmpeg-Runtime/README.md`。
- 管理器显示处理进度，只显示可读错误消息，不再向用户展示 PowerShell 堆栈。

## 使用与升级

完整解压 ZIP，打开 `CodexLiveBackground.exe`，点一次「装载服务」，之后点「换壁纸」选择素材。旧版用户关闭旧管理器后使用新版「装载服务」即可升级，兼容安装会保留当前壁纸和背景配置。

软件仍只有「装载服务」和「换壁纸」两个按钮，登录后在后台自动恢复。保留底部透明修复、每个素材 512 MiB、视频最长 10 分钟 / 最高 120 FPS 的限制。能够直接播放的视频保留原画质。

## 验证与适用范围

已验证真实 VP9 转换、当前 Codex 实际解码帧及缓存复用。WebM 验证回归覆盖 VP8、VP9、120 FPS、损坏或伪造容器、空视频块、错误轨道及尺寸 / 帧率 / 时长限制；同时验证 PowerShell 导入链和主题包导入。

适用于 Windows 10 / 11 x64 官方 Codex 稳定版。首次启用时普通启动的 Codex 可能需要用户保存输入并手动完全退出一次；工具不会强制关闭聊天。Beta 包和其他平台尚未支持。

本工具为非官方定制，与 OpenAI 无隶属关系。发布包包含源码和第三方许可，不包含个人壁纸、账号资料或 FFmpeg 二进制。
