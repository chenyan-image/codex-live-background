# v1.7.0.6

内部版本：1.7.0.26。稳定版。

- 新增内置奶蛙，素材来自 timerring/codex-pet-naiwa，九种原始动作接入任务、点击、拖拽、行走、边界回弹与额度卡片。图集无损转为透明 PNG，排除失败动作末尾两格透明占位，避免闪空；列表使用独立待机缩略图。
- 修复反复最大化／还原后窗口宽高每次增加约 14 像素的问题：分离托管无边框尺寸计算与原生缩放边框，保留四边缩放及圆角。
- 修复配色弹窗 HEX／RGB 数值被布局裁掉的问题，覆盖 100%、125%、150%、200% 缩放。
- 消除拖拽预热与正常播放重复解码同一图集的缓存。在奶蛙的固定场景中，图集解码缓存由 26.8 MiB 降为 13.4 MiB；不降低动画画质或帧率，不以强制 GC 或裁剪工作集制造降幅。
- 保留已有宠物、壁纸、活动范围、大小、配色、透明度及记录。包含前版副屏最大化、窗口白框、后台状态提示及碰撞边距修复。

## 安装与更新

- 新装或需要新增奶蛙素材：使用 CodexHub-1.7.0.6-Setup.exe，覆盖安装可保留原设置。
- 仅更新已有程序：在“服务与设置 → 更新软件”安装约 4 MiB 更新包；此通道继续保留素材，不附带新增奶蛙图集。需要奶蛙时运行完整 EXE。

原始来源、许可与第三方素材权利范围已记录在 source/assets/pets/naifrog/NOTICE.md；不将作者的 MIT 声明扩大为第三方角色素材授权。
