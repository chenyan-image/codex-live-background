# CodexHub 抖音功能预览 3

内部版本 `1.8.0.3`，功能分支 `codex/douyin-spark`。

- 点击“开始续火花”自动发现并打开或恢复抖音桌面版，等待窗口就绪后执行名单。
- 新增“定位抖音”，支持自定义磁盘和安装目录，保存后无需每次选择。
- 独立桌宠模式无需安装或登录 Codex，不启动 Codex 的任务、Token、额度和窗口读取。
- 修复控件读取超时后重试一直等待的问题；原生读取在短时进程中完成，超时和取消会结束该读取。
- 兼容不提供直接赋值接口的消息搜索框，增加焦点验证、Unicode 键盘输入和回读验证。
- 保留当天发送记录、找不到人跳过、同名待确认、停止任务和不发送的检查模式。

目前仍为独立体验分支，未合并到稳定版，未改变稳定更新渠道。真实联系人发送尚未验证。
