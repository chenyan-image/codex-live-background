# 统一安装与卸载

- MSI 提供路径选择页，允许选择其他本地盘；安装路径写入用户注册表，维护与卸载复用该路径。
- 管理器与后台程序统一位于安装目录，startup 子目录由 MSI 管理；AppData 仅保留用户数据和缓存。
- 桌面只生成 Codex 动态背景管理器快捷方式。升级移除已核验的旧 Codex（动态背景）入口，恢复被改过的普通 Codex 启动链接。
- 安装目录内提供独立卸载 EXE，调用对应 MSI 产品卸载。MSI 先移除服务、挂接和自启动，再删除程序文件，并清理明确归属的缓存、下载运行时和记录。
- Steam/桌面原始媒体不删除，Codex 独立配置目录包含登录及聊天相关数据，保留并在卸载说明中列明。
- 在隔离测试产品中验证非默认路径、修复、卸载和清理边界，不操作本机正式服务，不重复旧窗口测试。
