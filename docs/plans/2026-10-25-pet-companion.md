# CodexHub 桌面宠物功能分支

基线：v1.5.4.5。分支：`feature/pet-companion`。软件界面名称改为「CodexHub」，保留既有安装身份、资料路径、背景功能及托盘修复，避免更名造成两套安装。

- 左侧加入「桌面宠物」：九个内置形象（鲸鱼娘 deepseek酱、Boba、Tiko、Wangcai、Codie、奥黛塔、爱弥斯、穗穗、流萤·春日手信），另有白龙娘和小蕾米的作者素材加载入口。支持导入本地 Codex pet.json / PNG / WebP 图集 ZIP。
- 同一进程内的透明窗口播放原图集九种基础动作；可拖动、随机行走、双击互动和静音设置。管理器隐藏到托盘后宠物继续，退出管理器时统一释放。
- 范围可选 Codex 内或桌面。Codex 内模式只跟随本机官方包的可见窗口，使用客户区边界；窗口移动时宠物保持相对位置，最小化／关闭时隐藏。桌面模式按各显示器工作区约束，拖动可跨屏。碰撞时反向、压缩回弹并绘制方向星星，效果由程序生成，不另下动画运行库。
- 宠物上方默认蓝色小胶囊和单个高清开口额度环，执行/思考时三点旋转；点击展开268×220逻辑像素卡片，左侧额度条、倒计时，右侧 Token/重置页签。字体使用 Chakra Petch 与微软雅黑；两种周期从本机 app-server 的 account/rateLimits/read 读取。Token 曲线统计本机今日/7天/30天，不把缓存输入重复相加，不读取或上传聊天正文。
- 原生透明窗口和矢量圆环随屏幕 DPI 渲染；精灵保持比例。不另装 Python／Qt。导入 WebP 复用现有经校验的 FFmpeg 运行时，内置 PNG 图集离线可用。
- 素材逐个保留作者、来源、下载校验值，下载包未附素材许可的如实记录，不把第三方素材改称本仓库 MIT。白龙/小蕾米仅提供原素材加载入口，从本机或作者固定原发布准备并校验，原声明随本地副本保留。字体 Chakra Petch 使用 OFL；刷新图标使用 MIT Phosphor 原始 SVG。

验证以动作帧、边界反射、窗口跟随／隐藏、拖动、额度空值／真实读取、导入校验、托盘生命周期、单 EXE 打包为准；不重跑旧缩放／滑杆测试。功能分支先交付预览，不合并稳定主线。
