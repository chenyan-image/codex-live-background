# 主动连接

- 左下角和服务页的连接按钮调用 Connect，装载必要服务并验证连接，未运行 Codex 时由用户点击启动。
- 启动和每 20 秒调用 AutoConnect：仅在已有自启动配置时尝试恢复，不自动打开 Codex、不恢复用户主动卸载的服务。
- Connection 保留为只读快照。连接操作复用现有身份验证和 ConnectOnly 握手，不覆盖已正常连接的状态。
- 操作在后台运行，重复点击排队为一次重试；显示连接中、失败原因和完整悬浮提示，关闭时只取消自己启动的控制进程。
- 已运行的普通实例无法动态开启调试端口，保留聊天窗口，提示用户保存并手动完全退出后重试。
- 使用隔离模拟验证新连接行为，不重复窗口缩放、滑杆和旧界面测试。
