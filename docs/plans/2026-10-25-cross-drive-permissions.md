# 跨盘回滚权限

- 已确认现场：旧版卸载进入 RollbackCleanup 后，D:\Config.Msi 的 RBF 文件设置安全信息失败，错误 1926 / 5；不将该目录当作应用残留删除。
- 正式 MSI 清除 Summary WordCount 中“不需要提升权限”的声明，保留 Windows UAC 与回滚；隔离测试 MSI 仍声明不提升权限。
- 为已遇到此错误的用户提供小型授权安装入口，与同版 MSI 放在一起。入口钉住 MSI SHA-256，提升前后校验，并检查原始用户 SID，避免通过其他账号安装。
- 授权入口只启动标准 msiexec，不写盘根 ACL，不启用 AlwaysInstallElevated，不关闭安全软件或回滚。管理器从普通桌面快捷方式打开，避免继承管理员令牌。
- 非系统盘或用户数据目录之外的独立卸载工具按需请求同一用户的 UAC 授权。
- 自动测试只验证摘要权限位、包哈希校验与授权路径判定；真实 UAC 同意和现场受保护目录清理必须由用户完成，不宣称已验证此机安装成功。
