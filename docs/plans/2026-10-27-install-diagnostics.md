# 安装失败诊断和残留扫描

目标：另一台机器未安装 Codex 时也能完成 CodexHub 安装；缺少日志时让用户在失败机器自行扫描，并保留可读诊断。

安装器提供深度扫描和清理已确认残留。扫描只读目录、注册记录与本项目进程，不自动停止或删除；后台运行，可取消，有界扫描明确报告未完成范围。优先检查安装历史与常用目录，再遍历本地固定磁盘，跳过系统路径、链接、开发仓库和素材数据。

清理前列出具体路径；重新校验已知发行程序哈希或固定清单，并比较扫描时的文件身份。清理只使用可信文件列表，不按目录名递归删除。个人壁纸、宠物、设置与登录资料保留。未知文件仅报告。

窄修复：可验证的旧程序可从可信发行清单恢复损坏标记；其他目录无法核验的旧记录不影响新路径安装；同用户、已识别路径上的失效启动任务可移除。没有 Codex 或检测接口不可用时先完成程序安装，服务连接结果独立提示。

针对性验证：无 Codex、未登记目录、损坏标记、未知程序、扫描后文件变化、个人数据保留、开发仓库排除、取消、失效任务身份，以及现有盘符和卸载边界检查。验收以完整 EXE 的新入口、可读报告和无越界清理为准；不把本机隔离检查当成另一台机器的根因结论。
