# 1.5.4 基线的 EXE 安装修复版

- 恢复 v1.5.4 管理器与壁纸行为，版本标为 1.5.4.1；仅回移自定义程序路径和安装生命周期所需修改，保留六张轻量背景。
- 单 EXE 内嵌 ZIP 与清单，直接部署文件、配置当前用户服务和 Windows 应用卸载记录；新装及新版卸载不依赖 MSI。
- 显示路径选择、当前步骤、运行记录和最终结果。完整安装目录内复制同一 EXE 作为独立卸载工具，桌面仅一个管理器图标。
- 卸载工具先移至临时目录运行，停用计划任务与启动挂接，卸下皮肤，再停止本项目管理器、守护、监控、注入、预览、转码及控制脚本，确认退出后删除自有文件与缓存。
- 只通过已核验路径、用户和进程启动时间定位后台进程；不结束官方 Codex 聊天或其他应用的同名 Node/PowerShell 进程。
- 迁移旧 MSI 时只使用已知产品 ID；先备份并清理已核验的旧 MSI 管理文件，避免旧文件再进入 Config.Msi 回滚备份，再通过 Windows Installer 正式移除旧产品记录。失败则恢复文件并停止迁移，不伪造删除 MSI 注册表。
- 原始媒体、独立 Codex 登录资料和未知用户文件保留。每次递归清理前检查绝对路径边界与联接。
- 隔离验证直接安装、升级、卸载、自定义路径、进程退出、旧 MSI 一次性迁移与失败恢复；不重复管理器缩放和滑杆测试。
