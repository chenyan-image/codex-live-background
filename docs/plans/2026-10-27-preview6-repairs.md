# Preview 6 repair scope

Accepted user scope: task and quota cards inherit their own capsule/ring colors; preserve local data through in-app updates and check for a program update once per startup; unclipped, actionable connection footer with visible progress; upgrade preview.3/.4/.5 without rejecting verified historical files; bundle Flower Peach, whale girl and whale maid; keep white dragon downloadable; Codex-only pets attach exclusively to actual main windows; restore saved wallpaper after app/Windows startup.

Observed mechanisms:
- Native install marker is a union of historical and updated files, but the newer installer trusts only its own current filenames. Retired documentation, pet descriptors and former bundled video make legitimate upgrades fail. Use a closed catalog generated from verified historical release manifests, canonical relative paths and existing traversal checks. Reject unknown files; do not trust arbitrary installed manifests.
- Main-window discovery accepts any sufficiently large window belonging to the official process and prefers the foreground window. Reject owned/tool/popup windows and non-Electron main classes, share the criterion with visibility tracking.
- Footer click invokes read-only `Connection`; concurrent status requests are silently ignored. Route explicit clicks to `Connect`, show progress immediately, queue one retry, allocate adequate footer height, and repair a missing renderer skin without closing Codex.
- The watcher treats an existing session and early injection marker as sufficient, without periodically checking whether the saved background is still installed after startup hydration. Add bounded health checks and restore only the verified saved theme; respect pause/removal and do not restart Codex.
- Expanded cards hard-code blue colors. Generate task palette from capsule color and quota palette from ring color, including expansion origin, chart and refresh glyph.

Preserve all personal materials/settings/history through program updates. A separate daily-check record may be written, never reset user preferences. Fresh installations omit video decoder binaries and optional pet media; obtain the pinned, hashed decoder only when a selected feature needs it. Preserve existing downloaded pets and runtimes. Keep Flower Peach as the sole new bundled wallpaper. Publish a new immutable preview rather than replacing preview.5.

Order: historical upgrade proof -> window/connection/startup repairs -> card palettes/daily update -> cloud materials/slim build -> focused tests -> actual update and screenshots -> final EXE/update/assets and GitHub release.
