# 4K 视频与管理器改版

目标：原生 4K 优先，无法播放时逐级生成兼容副本；美化 Windows 管理器并提供卸载皮肤入口。

保留原生 Windows Forms 和离线运行能力，不加入浏览器框架。深色界面配薄荷绿强调色，主操作为换壁纸，次操作为装载服务和卸载皮肤。小字署名保留。应用图标采用 Phosphor Mountains 的矢量形状并附原许可。根据界面反馈移除系统浅色标题栏，使用一致的深色窗口按钮和可缩放边框。

输入视频最大 2 GiB，时长、帧率及尺寸仍有界。512 MiB 内的标准文件先直接验证；其他受支持 MP4/WebM 使用固定版本 FFprobe 验证源数据后转换。原视频不可修改。兼容副本按原尺寸（长边最高 4096）、2560、1920 逐级尝试，均为 VP9、最高 30 FPS，并经过真实 Codex 解码验证。权限拒绝、窗口隐藏或连接失败不触发降级。

卸载皮肤即时移除注入效果并关闭自启动和后台恢复，保留素材及独立登录数据，不终止 Codex。操作失败时明确说明状态，不误报完成。

验证包括真实 4K H.264、VP9 和分片文件、逐级降级与缓存回归、权限失败不转换、卸载幂等及失败处理、Windows PowerShell 解析、编译和多尺寸界面截图。
