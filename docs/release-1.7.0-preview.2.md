# CodexHub 1.7.0-preview.2

功能预览分支：`feature/pet-companion`；内部文件版本 `1.7.0.1`。稳定推荐发行版仍为 `v1.5.4.5`。

## 本次变化

- 宠物列表保留鲸鱼娘、鲸鱼女仆、白龙娘、小蕾米。鲸鱼女仆替换旧大肥鱼，使用 PC2005-cloud/dsh-pet 的 106 段原始透明动画；白龙与小蕾米保留作者材料加载入口。
- 统一任务开始、工作、结果、等待、完成、错误、空闲随机动作及长时间休息的动作链。正常动作播完再切换；拖拽、碰撞即时响应。
- 降低走动频率：停留 12～24 秒后低速走一小段，日常动作之间穿插约八秒待机。碰撞有压缩、侧倾、回弹和明显星星。
- 胶囊与圆环分别展开任务／额度，卡片从点击位置渐进展开，身体不移位、不缩放。
- 离线碎碎念使用内置文案，蓝色圆角气泡带尾巴与爱心、14 像素字体；每宠物独立开关、周期和权重，不调用模型、不消耗额度。
- 修复各宠物右键活动范围、菜单多屏 DPI 判断和任务栏按钮问题；左右键按压回弹，右键静音，左键音效嵌入程序。
- Windows 11 使用原生圆角，扩大边缘和四角命中区域，让子控件向主窗口让出缩放边缘。
