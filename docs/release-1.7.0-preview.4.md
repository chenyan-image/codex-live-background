# CodexHub 1.7.0-preview.4

内部程序版本 1.7.0.4，功能分支 feature/pet-companion。稳定版 latest 保持 v1.5.4.5。

## 本次变化

- 服务与设置在“重新检测”右侧增加“更新软件”。从本仓库发行页下载独立程序更新包，核对 SHA-256、文件长度、逐文件清单和软件路径白名单，再正常退出并重开管理器。失败回滚程序，更新安装清单以支持后续卸载。
- 更新排除壁纸与宠物素材、用户设置、运行时和启动服务二进制。保留原安装路径、启动参数、个人资料与历史记录。原目录附独立小型卸载入口，按当前安装清单工作。
- 本地导入不再在界面线程逐文件写入壁纸库，改为后台批量保存。宠物素材准备、转换和下载降低优先级，进度合并显示。
- 清除旧主题恢复造成的“纸上微光”失效记录，阻止启动时再次生成。用户自己导入的同名图片保留。
- 鲸鱼女仆的行走跳过静止起步段，有效动画与位移同步。新 100% 是此前实际大小的 80%，保存的滑条值、70%～150% 范围及胶囊比例不变。鲸鱼娘显示名去掉后缀，内部 ID 保留。
- 小蕾米默认入口移除，保留三项默认宠物；不清空已有个人素材或旧缓存。
- 内置雨樱只附静态封面，应用时从 GitHub 下载完整 4K 原片，已有有效原片复用。106 段鲸鱼女仆透明动画仍随包提供。
- README 改用新版实际窗口截图，先展示界面，支持格式表置后。精简历史致谢表，保留原始项目说明及必要第三方许可文件。

- 降低常驻内存：鲸鱼娘的启动动作缓存由约 9.94 MiB 降为 0.34 MiB，遍历全部动作后约 2.74 MiB；静态 GIF 缩略图由 48 帧改为单帧，隐藏预览释放图片。视频回收缓冲和过渡旧帧及时释放。
- Token 扫描改为按字节筛选和复用缓冲，不为无关日志创建大量字符串，保留原累计／去重／续读规则。同一约 20.8 MiB 日志、动作与预览测试中，独立测试进程私有内存由约 56.2 MiB 降为 34.6 MiB；这是固定场景结果，实际占用随宠物、画质、DPI 和打开页面变化。

## 发行方式

首次安装使用完整 EXE，可选择目录。后续使用软件内更新按钮，只下载程序更新包。雨樱 4K 原片作为单独发行附件，按需下载；不改变宠物随包策略。文件长度与 SHA-256 以发行页的 SHA256SUMS 和 CodexHub-Update.json 为准。

功能预览与稳定版分开，未将宠物代码合并到稳定主线，也未覆盖已有发布标签。
