# CodexHub 1.7.0-preview.5

内部程序版本 1.7.0.7，功能分支 feature/pet-companion。稳定版 latest 保持 v1.5.4.5。发布前追加三处配色与布局修复，因此递增内部构建号，确保本机候选 1.7.0.5／1.7.0.6 可以接收更新；对外版本为 preview.5，不覆盖已有发行。

## 更新内容

- 桌面宠物增加默认关闭的“跟随 Codex 自动启停”。最小化、隐藏、退出时正常关闭管理器与宠物，恢复或打开时在托盘启动，不弹出主窗口。失去焦点不退出；任一官方稳定版或 Beta 窗口可见就继续运行。
- 复用已有更新组件的轻量检测模式，不新增 EXE 或桌面图标。手动退出后的暂停有确认握手，下一轮 Codex 隐藏再恢复时重新启动。导入、更新、颜色／文件选择器和设置对话框打开时等待完成，手动打开软件可修改设置。
- 移除管理器中的“打招呼”和“随机动作”，保留宠物点击和右键动作；额度刷新和互动设置上移。
- 宠物列表下方可一键统一左侧按钮、中间胶囊和右侧圆环颜色，也可分别选择。修复左侧按钮不跟随改色的问题；已有设置自动继承原圆环颜色。
- 胶囊不透明度使用 0～100% 滑条，实时预览、松手保存，避免拖动中反复写盘。降低不透明度只改变底色，文字保持清晰。文字略微放大，100% 仍完整居中。
- README 增加原生 SVG 版本、Windows、EXE 大小、MIT 徽章和直接下载按钮，更新宠物页面截图。
