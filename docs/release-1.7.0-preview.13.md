# v1.7.0-preview.13

内部版本：1.7.0.16。

- EXE 安装器新增“深度扫描”：检查目标路径、磁盘空间、旧安装标记、旧 MSI 记录和当前用户的后台进程，扫描本地固定磁盘中的未登记安装；未安装 Codex 会单独说明，不作为安装失败原因。
- 新增“清理已确认残留”：先展示具体位置，再核验程序 SHA-256 或固定发行清单；只清理本项目已核验的程序文件和超过一天的已核验安装解压缓存。保留个人壁纸、宠物素材、设置、Codex 登录资料和同目录其他文件。
- 扫描在后台运行，可停止；有时间、目录数量和权限限制时明确标记为部分扫描。跳过系统目录、联接、开发仓库和素材数据，不宣称清理整台电脑的所有垃圾。
- 诊断报告保存到 `%LOCALAPPDATA%\CodexHub\Diagnostics`，包括人可读的“安装诊断.txt”和结构化报告。扫描只报告，不自动停止进程或删除文件。
- 修复可核验旧程序因安装标记损坏而无法修复安装；只使用已知发行程序哈希恢复清单，不信任损坏标记中的文件名。无法核验且不属于当前目标的其他目录保留并报告，不再阻止新路径安装。
- 修复当前用户、已识别安装路径上的失效启动任务因程序已删除而阻断安装。身份、参数或路径不匹配的任务保留。
- Codex 未安装或检测接口不可用时仍完成管理器安装；程序安装与背景服务连接结果分别报告。
- 保留任意合法安装目录、本地盘符根目录、离线 Node.js 和 FFmpeg 运行时。软件内更新不改变素材与设置；新扫描入口在完整 EXE 安装器中。

已完成隔离的安装诊断、残留归属与数据保留检查。未在用户真实磁盘运行深度清理，未远程扫描报错的另一台电脑；实际原因仍需在那台电脑运行此版扫描确认。
