# v1.7.0-preview.12

内部版本：1.7.0.15。

- 安装位置支持 C、D、E 等本地盘符、盘符根目录，以及中文、空格、符号等合法文件夹名；不要求固定目录名称，也不自动追加专用文件夹。
- 修复盘符根目录被截成盘符相对路径，以及根目录参数末尾反斜杠的引用问题。安装、更新和独立卸载器共用完整路径语义。
- 任意现有目录可用；按程序清单检查重名文件，遇到其他程序的同名文件保留原文件并明确指出冲突。Windows 系统文件目录、链接跳转路径及不可用磁盘仍会被拦截。
- 安装、更新或卸载在需要时请求当前账号的 Windows 授权。盘符根目录和已有共享目录不会被授予整目录修改权限。
- 固定记录文件：%LOCALAPPDATA%\CodexHub\installations.json。记录安装位置、版本和状态，修复安装与卸载器可从中自动定位，并核验实际安装标记。
- 卸载只删除程序清单文件和由这些文件留下的空目录，保留同盘其他文件与无关空文件夹，不扫描整盘。
- 完整安装包附带 Node.js、FFmpeg 和配套解码库，无需首次联网下载解码器；Windows 10/11 x64 自带的 .NET Framework 与 PowerShell 为系统前提。
- 尚未安装官方 Codex 时，先完成 CodexHub 程序安装并创建快捷方式，之后可在服务与设置中装载服务。
- 解压前检查临时磁盘空间；迁移检查结束后释放第一份临时文件，减少安装时的临时占用。

已执行隔离的路径、清单清理与安装历史检查。没有在真实 C/E 盘根目录执行安装卸载，也没有改变当前使用的 CodexHub 安装。软件内更新继续保留壁纸、宠物素材和个人设置。
