# 抖音续火花 · 功能分支

基于 CodexHub v1.7.0.6，开发分支为 `codex/douyin-spark`。壁纸、桌面宠物、任务与额度等原有功能保留。此分支不替换稳定版下载和更新渠道。

## 使用

1. 打开完整体验目录内的 **CodexHub-抖音预览.exe**。该入口使用本目录的 `DouyinPreviewData`，不改正式安装的设置和服务。
2. 体验版的桌宠独立运行，不要求安装或登录 Codex。到左侧 **抖音续火花** 添加联系人，名称必须与抖音消息列表中的昵称或备注一致。
3. 先选择 **检查名单（不发送）**。软件自动查找、打开或恢复抖音，等待主窗口就绪，再连接消息列表。任务开始后，管理器暂时收进托盘，避免挡住抖音；宠物会移动到消息入口、选中的联系人和表情旁。检查模式找到“续火花”后结束，不点击发送。
4. 确认名单后，选择 **开始续火花**，或开启 **打开抖音时自动续火花**。CodexHub 需保持运行，可收进托盘。
5. 可从托盘菜单选择 **停止续火花任务**；打开管理器后也可按 **停止任务**。点击宠物或将抖音切到后台会结束当前任务。结束后宠物回到原处，活动范围和大小不变；从管理器发起的任务结束后会恢复管理器。

抖音安装在 C、D、E 等自定义位置时，软件会查找正在运行的程序、安装记录和常用安装位置；未识别时可点击 **定位抖音** 选择 `douyin.exe`，只需设置一次。没有安装抖音时会提示先安装；没有登录时需要自行完成登录。

控件读取使用短时隔离进程，超时或取消后会结束该进程，下次可以重新开始，不会持续占着后台。独立桌宠模式不会启动 Codex 额度、任务、Token 或窗口读取；原有 Codex 模式继续保留。

预览版 4 优先使用 Windows 自带的局部文字识别定位消息栏和表情区域，再通过原生控件点查核对完整联系人名称及搜索内容。中文相似字不做模糊匹配；缺少可用的 Windows OCR 时回退到控件定位。无需安装 Python，也不调用 Codex 或在线识别服务。

本机抖音的直接赋值接口会回显文字，但不一定触发真正的搜索。因此消息搜索统一在确认焦点后使用 Unicode 键盘输入；不使用剪贴板，不按回车。输入后通过可访问值或文字接口回读核对，核对失败时不继续发送。

宠物的引导移动按距离控制在约 0.18～0.55 秒。页面等待阶段设有 8 秒的轮询预算，单次隔离读取另有超时；任务结束显示本轮耗时。目标是缩短一轮操作时间，尚未验证“一分钟内完成真实发送”，耗时也会随名单人数和抖音响应速度变化。

## 处理规则

| 情况 | 软件行为 |
| --- | --- |
| 找到唯一同名联系人 | 打开对话，复核标题，点击表情中的“续火花” |
| 搜索完成后无匹配 | 标记“无此人”，继续下一位 |
| 出现多个同名匹配 | 标记“同名待确认”；请先在抖音设置唯一备注 |
| 当天已处理 | 跳过，防止重复发送 |
| 已点击但未读到发送回执 | 标记“已点击·待确认”；当天不自动重发 |
| 控件未出现、加载超时、对话改变 | 停止或跳过，并显示具体原因，不冒充“无此人” |

自动模式在抖音位于前台时开始，每次遍历启用名单一次。为避免不存在的名字反复触发，自动检查有 30 分钟间隔。发送前保存当天记录，即使随后程序中断，也不会自动重复点击。仅自动点击已设置联系人的“续火花”，不抓取登录令牌，不调用私信接口，不保存聊天正文。

当前视觉路径不根据火焰图像或表情面板关闭推断发送成功。未获得明确回执时，结果保守显示“已点击·待确认”，请在抖音核对；这不会触发当天自动重发。

## 当前适配范围

- Windows 10/11 x64，官方抖音桌面客户端；使用 Windows 局部 OCR 和原生可访问控件接口。
- 按界面文字、表情图像及控件名称定位，位置变化时重新核对，支持副屏的负坐标。
- 需要已登录；登录、权限提示或抖音界面变化造成无法识别时，会停下并显示原因。
- 这是一项桌面操作：执行时请让抖音保持前台。网页版、手机投屏和第三方客户端不在这一版的适配范围内。
- 开发检查不发送真实私信；实际发送结果需要用自己设置的测试联系人确认。
