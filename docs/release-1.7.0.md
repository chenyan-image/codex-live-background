# v1.7.0

内部版本：1.7.0.18。正式稳定版。

- 正式发布动态壁纸、桌面宠物、任务与额度卡片、Wallpaper Engine 壁纸库和软件内更新。
- 修复旧安装标记包含 `docs\release-1.7.0-preview.11.md` 时无法升级、修复或清理的问题。
- 从本项目已发布且 EXE SHA-256 核验一致的 preview.9～14 安装包中提取原始 manifest 和程序哈希，补齐历史文件清单；不按任意文件名或扩展名放行。
- 后续完整安装包保留仓库中已有版本的更新说明，使这些准确文件名持续包含在可信安装清单中，避免只携带当前说明导致旧标记再次失配。增加的只是小型文档。
- 旧程序已经缺失时，可用已固定哈希的原始发行清单核验残留；未知清单、目录越界、任意附加文件和文件类型变化仍会被拒绝。
- 针对诊断报告中的同名共享目录和 preview.11 文件，验证完整旧安装及程序缺失的残留场景，清理保留同目录的其他文件。
- 沿用运行时心跳、日志更新的兼容修复，以及未安装 Codex 时先安装管理器的行为。

已用哈希核验的真实 preview.11 安装包复现旧版错误并完成针对性回归。未修改报错电脑的安装目录、壁纸、宠物素材或设置；请使用本版完整 EXE 安装器重试。
