# 抖音功能分支验证记录

- 基线：v1.7.0.6；分支：codex/douyin-spark；体验版本：1.8.0.3。
- 流程检查：52 项，通过。包括自动启动顺序、无安装时停止、启动中取消、未确认发送不重试、读取进程超时及取消后可重新请求，以及搜索框键盘回退、错误焦点不输入、输入回读失败不放行。
- 无 Codex 运行：11 项，通过。未创建额度读取器、任务监视器和 Token 读取器；活动范围不依赖 Codex 窗口。
- 原宠物渲染：24 项，通过，180 帧只分配一次画布，画面校验值与基线相同。
- 实机只读：恢复抖音后，两次成功取得消息控件，分别约 5.8 秒、5.6 秒；无真实消息发送。
- 旧的 .NET 控件遍历在本机抖音上超时，已替换为 Windows 原生 COM 控件接口。读取由短时子进程隔离，不保留常驻读取进程。
- 此分支尚未对真实联系人执行发送验证；稳定版及其更新渠道未改动。

用户实机反馈的“搜索框暂不支持自动输入”已在预览版 3 加入键盘输入和 Legacy/Text 文字回读兼容。该回退已通过隔离检查；真实抖音上的完整输入、逐人发送仍需继续验证，不能把隔离检查当成已发送消息的证据。
